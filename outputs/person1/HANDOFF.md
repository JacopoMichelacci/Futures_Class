# Issue #14 — Contract destination (Part 3)

**Status: implementation staged; empirical evaluation NOT YET RUN OR VERIFIED.**

## Scope and frozen choices
- Universe: ZC, ZS, ZW; frozen Section 0 sample of 148 return sessions (2026-03-02 through 2026-09-30).
- Fixed destination reference AUM: **$10,000,000**.
- Four locked rules: next deferred, second deferred (fallback to next if only one), closest to 45 observed sessions, closest to 75 observed sessions.
- Destination is selected only on existing baseline roll events; event dates, target weights, sizing, capacity, nearest-integer rounding, benchmark, and P&L engine are unchanged.
- Ranking: realized daily tracking RMSE in basis points on one common valid-date intersection, subject to at least 100 dates and 70% survival. Differences strictly below 0.1 bp require the agreed Part V tie priority; without it the outcome is unresolved.

## Implementation
- `src/selection/rules.py`: deterministic destination selection and invalid-path flags.
- `src/selection/analysis.py`: fixed-event path generation, common-date comparison, RMSE, coverage gate, diagnostics, and tie handling.
- `src/selection/exports.py`: summary/daily CSV, two PNGs, generated empirical handoff.
- `scripts/run_person1.py`: real Section 0 adapter; loads hash-checked frozen inputs, sizes each candidate using `holdings_from_contract_path`, values via `portfolio_pnl`, and verifies the shared benchmark against frozen baseline returns.
- `Section 1 - Contract Destination (Varshini)/Section 1.ipynb`: analysis and result-inspection notebook.
- Existing selection test suite: 17 tests passed before this update. Re-run after integration.
